# Skill_Bridge
✦ SkillBridge — Platform edukasi interaktif berbasis gamifikasi yang menjembatani pembelajaran keterampilan digital modern (Teknologi, Desain UI/UX, &amp; Komunikasi) dengan pengalaman seru layaknya bermain game. Dilengkapi sistem XP, Koin, Tantangan Harian, Studio Proyek, serta Mini Game pengasah logika yang dapat di-install langsung ke perangkatmu
